# 每日词库 MVP

一个使用 Flask 和 SQLite 构建的本地背单词网页应用。

## 开发与维护

- 项目开发规范见 `AGENTS.md`。
- 历史变更记录见 `CHANGELOG.md`。

## 当前功能

- 创建学习日期
- 自动记住上一次选择的学习日期
- 主界面只展示当前选择日期的词库
- 在独立日期词库页面折叠查看并切换其他日期
- 连续添加单词时自动保持输入焦点，点击输入区域外退出
- 输入单词后按需查询本地 PDF 词书
- 提取词书中的释义和重点词组
- 将数据保存在本地 SQLite 数据库
- 按日期显示每日词库
- 每日词库列表仅显示单词和释义，词组保留在背诵模式中
- 删除误加或不需要的单词
- 按日期进入背诵模式并随机显示英文
- 使用熟练度、错题次数和到期状态进行加权随机抽词
- 点击后显示释义，使用“不会 / 模糊 / 认识 / 熟练”记录结果
- 显示当前熟练度、今日作答和待复习进度
- 在设置页查看和切换当前 PDF 词书
- 在保留单词和日期的前提下重置全部复习进度
- 使用更简洁的日期选择提示，并在设置页切换本地主题颜色

## 主题颜色

设置页提供原始绿、海湾蓝、薰衣紫和柔粉四套主题。原始绿仍是默认配色；选择结果只保存在当前浏览器中，不写入数据库。

## 更换 PDF 词书

当前使用的 `六级词汇闪过.pdf` 已统一存放在 `books` 文件夹中，后续词书也放在该文件夹管理。

1. 将新的 PDF 词书复制到项目的 `books` 文件夹。
2. 打开网页右上角的“设置”。
3. 在 PDF 词书列表中点击“切换到这本”。

主界面会显示当前使用的词书。选择结果保存在本机
`instance/book_config.json`，不需要修改代码或重启应用。项目已忽略所有 PDF 文件，
避免新的本地词书被误提交到 Git。

设置页的“重置全部复习进度”会将所有单词恢复为 1 级，清空答对答错次数和学习记录，
并从当天重新安排复习。该操作不会删除日期、单词、释义或词组。

## 间隔重复规则

- 熟练度分为 1 到 5 级，对应“完全不会”到“已经掌握”。
- 新单词和答错较多的单词拥有更高抽取权重；逾期单词额外提高权重。
- 当前日期中的新单词与所有已到复习日期的旧单词共同进入候选池。
- 等级 1 到 5 的默认复习间隔分别为 1、2、4、7、15 天。
- “不会”会重置为 1 级并保留在当天队列；“模糊”安排到明天；“认识”和
  “熟练”会提升等级并延长间隔。
- 有多个候选词时不会连续抽到同一个单词。

抽词和调度规则位于 `spaced_repetition.py`，Flask 路由仅负责数据库读写和页面渲染。

## 本地运行

### 推荐：双击启动

在项目文件夹中双击 `start.bat`。脚本会自动完成以下操作：

- 首次启动时创建 `.venv` 并安装项目依赖
- 启动本地 Flask 服务
- 自动在默认浏览器中打开网页

使用期间请保留弹出的命令窗口；关闭窗口或在窗口中按 `Ctrl+C` 即可停止应用。以后再次使用时只需重新双击 `start.bat`。

### 手动启动

```powershell
cd D:\Codex\program\English
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

电脑浏览器访问 <http://127.0.0.1:5000>。

手机访问时，确保手机和电脑连接同一个 Wi-Fi，然后查看启动输出中的局域网地址
（例如 `http://192.168.1.10:5000`）并在手机浏览器打开。Windows 首次询问防火墙
权限时，只需允许专用网络访问。

数据库会在首次运行时自动创建于 `instance/vocabulary.db`。PDF 只在用户查询时读取，
不会被批量导入数据库；SQLite 只保存用户添加的词条结果。

## MVP 暂不包含

- 单词内容编辑
- 登录和多用户
- 用户账户与云同步
